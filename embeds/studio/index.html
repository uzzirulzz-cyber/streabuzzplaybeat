Before you ship

  • API key exposure — AI Studio Build apps commonly bake a Gemini API key into the served JS. Embedding that on a public site exposes the key to every visitor. Restrict the key, or proxy the calls through a small backend.
  • Review model-generated code — skim for remote <script>s, eval, unexpected domains, or telemetry.
  • Honor PlayBeat TV doctrine — if the Studio app lists channels or streams, every entry must come from authorized sources and respect the LIVE/OFFLINE/UNVERIFIED health map.
